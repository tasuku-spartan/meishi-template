# デジタル名刺テンプレート

NFCカードとQRコードで渡すデジタル名刺です。
メンバーはこのリポジトリをコピーして Claude Code と会話するだけで、自分の名刺ページを GitHub Pages に公開できます。

## ファイル構成

```
├── CLAUDE.md               Claude Code が読む入力〜公開の手順（メンバーは読まなくてOK）
├── index.html              名刺ページ本体（管理者が管理）
├── profile.js              メンバーごとの情報（Claude Code が書き換える）
├── .nojekyll               GitHub Pages 用
└── assets/
    ├── company-logo.svg    会社ロゴ（管理者が差し替え）
    ├── company-logo-light.svg  濃い背景用の白抜きロゴ（任意）
    └── photo.jpg           メンバーの写真（作成時に追加される）
```

## 管理者がやること（最初に1回）

1. このフォルダを GitHub にリポジトリとして push する。
2. GitHub の Settings → General で「Template repository」にチェックを入れる。
3. `assets/company-logo.svg` を自社ロゴに差し替える。
   - 濃い背景色でロゴが見えにくい場合は、白抜き版を `assets/company-logo-light.svg` として追加する（背景色に合わせて自動で使い分け）。
   - PNG を使う場合は、`index.html` 冒頭の `ASSETS` のファイル名を変更する。
4. 起動アニメーションでアプリロゴを使う場合は、画像を `assets/app-logo.svg` などに置き、`ASSETS.appLogo` にそのパスを書く（空のままなら内蔵のマークを表示）。

## メンバーの手順

詳しくは「デジタル名刺 作成マニュアル（メンバー向け）」を参照。大まかな流れは次のとおりです。

1. GitHubアカウントを作り、このテンプレートの「Use this template」から自分のリポジトリ（Public、名前は `meishi`）を作る。
2. 写真を `assets` フォルダにアップロードし、Settings → Pages で main ブランチを公開する。
3. ブラウザで claude.ai/code を開き、自分のリポジトリを選んで「名刺を作りたいです」と送り、質問に答える。
4. Claude が作業ブランチに push したら、Create PR → Merge pull request で反映する。
5. 名刺のURLを、既存のNFCアプリでカードに「URL」として書き込む。

内容を変えたいときは、claude.ai/code で「名刺を更新したい」と伝え、同じくマージするだけ。URLは変わらないので、カードの書き直しは不要です。

## 受け取った人が見る流れ

1. 起動アニメーション（会社ロゴ または アプリロゴ、5秒。タップで先へ進める）
2. スクランブルするメッセージ
3. 名刺ツアー：ようこそ！ → 私の名前です → こんな人間です → SNSでつながりませんか？
4. 最後のページで SNS へ移動、連絡先に保存（vCard）、QRコードの表示ができる

## メモ

- 無料プランの GitHub Pages は Public リポジトリのみ対応。ページは URL を知っている人なら誰でも見られる（検索エンジンには載らない設定済み）。
- 公開URL（約40〜60文字）は NTAG213 などの一般的なNFCタグに収まる。書き込み後にタグをロックする場合は、URLが確定してから（ロックは元に戻せない）。
- メンバーが自分のQRをその場で見せたいときは、公開URLの末尾に `?qr` を付けて開く。
- SNS の表示は文字のバッジです。各サービスの公式アイコンを使いたい場合は、各社のブランドガイドラインに沿って管理者が `index.html` を調整してください。
